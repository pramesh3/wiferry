Tips for iPhone
  • Photo Library may convert HEIC photos to JPEG. To keep originals, save them to Files first (Share → Save to Files), then use Choose File.
  • If "Optimize iPhone Storage" is on, some photos live in iCloud only and can't be sent offline.
  • Don't lock the screen or switch apps while sending.

From PC

Download all
    Where do downloads go on iPhone?
    • Find them: in Safari tap AA → Downloads, or open Files → Downloads.
    • Keep them on the phone, not iCloud: Settings → Apps → Safari → Downloads → On My iPhone (one time).
    • Download all saves a dated zip, e.g. WiFerry-2026-11-17_15-42.zip. Tap it once in Files and it becomes a folder with all the files.
    • Ignore the "Open in…" screen after downloading. The file is already saved.
    • To add a photo to Photos: open it in Files → Share → Save Image.
