# Roadmap

WiFerry stays small on purpose. Everything here keeps the three rules: **offline only**, **nothing to install on the phone**, **one file on the PC**.

Want to help? Look for [`good first issue`](https://github.com/pramesh3/wiferry/labels/good%20first%20issue) and [`help wanted`](https://github.com/pramesh3/wiferry/labels/help%20wanted), or open an issue to discuss an idea first.

## Next

- **Tested on more devices.** Real reports from Windows 10/11 PCs, more Linux desktops, older iPhones and Android phones. Use the *Device test report* issue form.
- **Easier installs.** winget and Scoop on Windows, AUR on Arch Linux.
- **Small quality-of-life fixes on the PC page:** paste files with Ctrl+V, a copy-link button next to the QR, speed and time left while sending.

## Later

- **Save phone downloads into a dated folder automatically**, using an optional iOS Shortcut, so each session lands in `Files → WiFerry → 2026-11-18`.
- **macOS release.** It already builds from source; it needs testers and signed downloads.
- **Send text and links**, not just files (paste a link on the PC, tap to open on the phone).

## Not planned

- Cloud relays, accounts or anything that needs internet.
- A native phone app. If you want one, [LocalSend](https://localsend.org) is excellent.
